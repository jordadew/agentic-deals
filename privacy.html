Privacy policy

Last updated: 9 October 2026

agentic-deals is a private tool with one user: its owner, Jordan Adew. It accesses only the owner's own Gmail account, with the owner's consent.

What it accesses

Using the Gmail API, it reads incoming and sent messages, applies labels, and creates drafts or sends replies that the owner has approved.

How data is used and stored

Messages are processed on the owner's own computer to identify brand-partnership emails. Extracted deal details (brand, contact, offer, dates) are stored in a database controlled by the owner. Message text may be processed by an AI model to classify emails. No data is sold, shared for advertising, or used for any purpose other than the owner's own deal tracking.

Google user data

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
